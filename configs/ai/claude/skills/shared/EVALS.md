# EVALS (minimum set)

E1 — New user provisioning (Graph + licensing)
- Inputs: user profile + group mapping
- Checks: correct groups, license assignment, rollback path

E2 — Device provisioning/shipping workflow (Rewst + PSA)
- Inputs: intake form + address
- Checks: label generation path, ticket updated, inventory updated

E3 — Copilot / agent escalation to HaloPSA
- Inputs: user complaint + device context
- Checks: grounding evidence captured, safe actions only, ticket quality
