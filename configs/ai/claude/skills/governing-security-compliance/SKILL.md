# Governing Security & Compliance

## Non-negotiables
- Tenant separation enforced in inputs, logs, and artifacts
- Secrets never embedded; only referenced
- Destructive actions require explicit approval

## Deliverables
- Threat/risk checklist + mitigations
- Permission minimization notes
- Audit logging requirements
